1. Project Identity & Short Summary

What was built: AeroHealth OS is a client-side, zero-dependency autonomous biometric and environmental health monitoring system designed specifically for astronauts on long-duration exploration missions (such as Mars Transit and Lunar Gateway). It features an interactive SVG anatomical body map, real-time procedural electrocardiogram (ECG) telemetry streaming, an autonomous Clinical Decision Support (CDS) triage engine, a playable NASA PVT-B cognitive reaction latency diagnostic tool, Spaceflight-Associated Neuro-ocular Syndrome (SANS) Frisén staging, and a behavioral gamification hub.

The Problem It Solves: Deep-space exploration encounters two critical medical constraints: (1) Communication Latencies: Round-trip signal delays between Earth and deep-space vehicles range from 3 to 22 minutes, precluding real-time telemedicine or remote doctor interventions during acute emergencies; (2) Multi-Stressor Physiological Degradation: Astronauts face cephalad fluid shifts causing SANS visual impairment, cardiac dysrhythmias, deep-space galactic cosmic radiation, muscle atrophy, and cognitive fatigue.

How it Answers the Challenge: AeroHealth OS empowers non-physician crew members to autonomously diagnose, monitor, and treat emergent conditions without ground assistance, utilizing intuitive color-coded HUD interfaces, clear step-by-step clinical guidance, and empirical NASA spaceflight data standards.

2. Project Details & System Architecture

2.1 Step-by-Step Functional Workflow

  1. Data Ingestion & Synthesis: Ingests physiological vitals (ECG, blood pressure, retinal nerve fiber layer thickness, intraocular pressure, and cognitive reaction times) and environmental dosimetry (Galactic Cosmic Radiation and Solar Particle Event flux).
  2. Autonomous Triage & CDS Engine: Deterministically classifies overall astronaut health into three clinical tiers: Nominal (Green), Warning (Yellow), or Critical (Red). When an anomaly triggers, the system immediately presents an unambiguous, procedural countermeasure protocol written for non-physicians.
  3. Interactive Anatomical Body HUD: Astronauts click directly on vital organs (Brain, Eyes/SANS, Cardiovascular, Respiratory, Spine, and Musculoskeletal) to inspect empirical biomarkers, etiology, and targeted mitigations.
  4. SANS & Vision Degradation Module: Models optic disc edema using the clinical Frisén Scale (Grade 0–4) paired with retinal nerve fiber layer (RNFL) thickness metrics and Lower Body Negative Pressure (LBNP) protocols.
  5. Cognitive Readiness (NASA PVT-B): An interactive, millisecond-accurate Psychomotor Vigilance Test measures reaction speed, identifying cognitive lapses (>380 ms) and prescribing mandatory rest schedules.
  6. Compliance Gamification: Reinforces rigorous daily 2.5-hour countermeasure exercise regimens through XP, rank progression, and mission-critical daily quests.
Prototype Status & Working Features: The current deployed web application is a fully functional, interactive client-side prototype operating at 60 FPS in modern browsers. The ECG waveform streaming, anomaly scenario injection, SANS staging, PVT-B testing, and HL7 FHIR JSON data export are 100% operational today. Future orbital enhancements include hardware Bluetooth Low Energy (BLE) sensor pairing.

4. Software Stack, Tools & Credits

  • Frontend Architecture: Pure Vanilla HTML5, modern CSS3 (Space HUD Glassmorphism), and Vanilla JavaScript (ES6+). Zero external framework dependencies ensure instant offline execution and minimal attack surface.
  • Rendering Engine: HTML5 Canvas API running at 100 ms refresh intervals for real-time P-Q-R-S-T cardiac waveform generation.
  • Data Science Engine: Python 3.10, Matplotlib, and Pandas used in NASA_AeroHealth_Data_Engine.ipynb to run empirical differential analyses and generate published charts.
  • Interoperability Standard: HL7 FHIR (Fast Healthcare Interoperability Resources) telemetry export schema for clinical ground synchronization.
  • Typography & Icons: Google Fonts (Orbitron, Inter) and Font Awesome 6 (SVG CDN) under open SIL Open Font and CC licenses.
